# Third-party material

The official online bin packing generator and public EoH/FunSearch reference code originate from the EoH project and the paper:

Fei Liu et al. *Evolution of Heuristics: Towards Efficient Automatic Algorithm Design Using Large Language Model*. arXiv:2401.02051, 2024. The archived Appendix B.3 / Figure 6 supplied the reference rules.

- Repository: https://github.com/FeiLiu36/EoH
- Pinned commit: `472545785c936dcfc863d2bc0d6109cf23c7ce62`
- Generator hash and original source metadata: `third_party/eoh/repository_version.json`
- Original MIT license text: `third_party/eoh/LICENSE`
- Public rule copies: `assets/rules/EoH.py` and `assets/rules/FunSearch.py`

The historical source programs were generated before this GP study using the Qwen2.5-Coder 3B Instruct Q4_K_M model. Archived model metadata preserve its supplied license and template information. Model weights are not included or redistributed. This project makes no new LLM request when extracting, searching or evaluating the saved rules.

No project-wide license is assigned to all contents by this repository. Existing third-party notices and licenses remain applicable. The assignment specification and historical course/project material are included for the private course submission context.
