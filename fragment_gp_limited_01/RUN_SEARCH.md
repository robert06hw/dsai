# 正式入口

python timed_run.py。沿用原版計時觀察器：只記候選評估開始／完成、完整run含建構選拔checkpoint IO牆鐘；不更改搜尋選擇。execution_instrumentation_lock在第一個完整候選評估前固定觀察器與pre_search_lock。

共用初始化的48次實體成本單獨列出；名義總預算1152、1008子代名額。每run曲線計相同seed初始化的共同成本，加該run新候選與構造／選拔時間。物理總成本不把共用初始化計三遍。

九個搜尋全部結束後才建立pilot_val診斷與固定參考工作。歷史索引只用于禁止完整根注入及日誌診斷，不參與父代機率或品質選拔。沒有新LLM、沒有新分群、沒有新模型。
